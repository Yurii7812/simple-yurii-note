# 01 概要

## 目的

- Markdown ファイルをノートとして使い、ノート同士の関係（親・被リンク）をリンクで管理する。
- Vim 上で「書く・繋ぐ・辿る」を高速に行う。プラグインは `simple_yurii_note`。
- `Yurii_PKM`（v2 形式）から、**Child セクションを廃止して本文に一本化した**簡素版がこちら。

## 環境

- OS: Debian 系 Linux
- デスクトップ: KDE Plasma（Wayland）
- 端末: Konsole / シェル: bash
- エディタ: Vim（`~/.vimrc-simple-yurii-note`）
- IME: fcitx5（Insert を抜けると英語、戻ると復元）
- エージェント設定: opencode（`~/.config/opencode/AGENTS.md`）

## データの流れ

```
利用者
  └─ yurii-note アプリ（Konsole + vim -u ~/.vimrc-simple-yurii-note）
        └─ simple_yurii_note プラグイン（~/.vim-simple-yurii-note/simple-yurii-note）
              └─ ノート: ~/files/yurii-note/*.md
                    └─ 同期: python/note_format_v2.py (update / update_one)
```

## 紙のPKM（フォルゲゼッテル、2026-10-07〜）

紙ノートのスキャンにフォルゲゼッテルIDを付けて vault へ取り込む仕組み。
詳細・罠は `06-引き継ぎ.md`。

- 入口: `\F`（`:SimplePaperIndex`）で紙PKM Index を作成/オープン → `\f`（`:SimpleScan`）で
  番号付け GUI（`python/folgezettel_scan.py`）→ 画像を vault 直下へ移動して同期。
- 実体: `python/paper_pkm.py`（ID 解析・Index/グループ/Folgezettel-Index 再生成・同期）。
- vault 直下にできるファイル: 紙PKM Index（タイムスタンプ名・`paper_index: true`）、
  `Index_write.md`（手書きの `キーワード(よみ): 1,1a10b,3`）、`Folgezettel-Index.md`
  （全IDの一覧）、`<ID>.jpg`（スキャン画像）、各スキャンのタイムスタンプ名ノート
  （`title: <ID>`・`folgezettel: <ID>`・画像埋め込み）、複数IDのキーワードの
  グループノート（`attribute: group`・`paper_keyword: <キーワード>`）。
