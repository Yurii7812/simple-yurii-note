# 04 キー操作（主なもの）

専用環境: `vim -u ~/.vimrc-simple-yurii-note`

## ノート作成

| キー | 動作 |
| --- | --- |
| `zn` | 子ノート作成（`h`=今のノートのカーソル直下 / `Enter`=本文の最後 / `p`=今のノートの `### Parent` 末尾 / `o`=孤立）。`h`/`Enter` は新ノートの `### Parent` に元ノートが入る。`p` は元ノートが**子**になるので新ノートの**本文リンク**に元ノートが入る（`o` はリンク無し） |
| `zk` | グループノート作成（front matter に `attribute: group`）。位置キーは `zn` と同じ |
| `zk`（ビジュアル） | 選択範囲を**中身にした**グループノートを作成。選択はグループへのリンクに置き換わる。グループの `### Parent` は今のノート。作成後グループを開く |

## リンク

| キー | 動作 |
| --- | --- |
| `\l`（ノーマル） | カーソル下のファイル名をリンク化 |
| `\l`（ビジュアル） | 選択範囲をリンクにして**新ノート作成**。新ノートの `### Parent` には元のノートを**確認なしで**書く。作成後そのノートを開く |
| `\p`（ノーマル） | リンク 1 本を今のノートに追加（`za` と同じ。`h` / `Enter` で位置を選ぶ） |
| `\p`（ビジュアル） | クリップボードのファイル名または URL を選択範囲のリンクに（ノートは開かない）。ファイルマネージャのコピー（`file://` URI）もローカルパスに直して扱う |
| `za` | リンク 1 本を今のノートに追加（`h`=カーソル直下 / `Enter`=本文の最後 / `p`=Parent末尾 / `r`=Related）。相手は**カーソル下のリンク → 無ければクリップボード**。相手側の `### Parent` には**書かない** |
| `zA` | `za` と同じだが、追加前に**表示名**を入力する（既定は `za` が使う表示名。空 `Enter` / `Esc` で中止）。Vim 標準の折りたたみ `zA` は上書きされる |
| `zp` | 同じ追加（`h` / `Enter` / `p` / `r`）をしたうえで、`h` / `Enter` のときは**今のノートを相手の `### Parent` に書く**。今のノートがグループなら親は sync が書くので何もしない |
| `\L`（ノーマル） | 全ノートを**全文検索（タイトル優先・表示はタイトル）** → カーソル位置にリンク（`[タイトル](相対.md)`）を挿入（`:LinkPick`） |
| `\L`（ビジュアル） | 同じ検索でノートを選び、**選択範囲をリンクで置換**（表示テキストは選択していた文字列。空ならノートタイトル） |
| `\P` | カーソル下の `.md` リンク先の `### Parent` に、**今のノートを確認なしで** 1 本足す（`\p` の確認プロンプトの代わり） |
| `zo` | カーソル下の `.md` リンク先ノートの**見出し（アウトライン）**を fzf で選び、リンク先に `#スラッグ`（GitHub / VS Code 互換）を付ける。右ペインに本文プレビュー。先頭の「（見出しなし）」で解除。タイトルと同じ H1 と `### Parent` / `### Related` / `### BackLink` は一覧に出ない（BackLink は同期で作り直されるため対象外）。詳細は `02-ノート形式.md` |

## 位置キーまとめ

`zn` / `zk` / `za` / `zp` / `\p` は「リンクをどこに置くか」を 1 打で聞く。

| キー | 置き場所 |
| --- | --- |
| `h` | 今のノートのカーソル行の直下（本文） |
| `Enter` | 今のノートの本文の最後（`### Parent` の直前） |
| `r` | `### Related` に**相互追加**（今のノートと相手の両方。無ければ見出しを作る。`za` / `zA` / `zp` のみ。片側で消すと次回同期で反対側からも消える） |
| `p` | 今のノートの `### Parent` 末尾（`zn` / `zk` / `za` / `zA` / `zp`） |
| `o` | リンク無し（孤立）。`zn` / `zk` のみ |
| `Esc` / `q` | 何も追加しない |

- リンクは**1 本だけ**取る（`za` / `zp` / `\p`）。`zn` は新規ノート 1 枚。
- リンクの候補は「**カーソル下のリンク → クリップボード**」の順。
- `zn` / `zk` で新ノート側に元ノートをどう書くかは位置キーで決まる。
  - `h` / `Enter` … 元ノートが**親**。新ノートの `### Parent` に元ノートを置く。
  - `p` … 元ノートが**子**（今のノートの `### Parent` に入るので）。新ノートの
    **本文リンク**に元ノートを置く。ここを `### Parent` にすると向きが逆になり、
    循環して読めなくなるため。
  - `o` … リンク無し（孤立）。
  詳細は `06-引き継ぎ.md`。

## 新規ノート（`zn` / `zk`）の完成形

`h` / `Enter`（元ノートが親）:

```markdown
---
time: 2026-09-27 07:48:50
title: 260927074850
---

# 260927074850

### Parent
[2026-09-26-sa-久しぶりの日記これまでのまとめ](260926174458.md)
### BackLink
```

`p`（元ノートが子。`zk`=グループの例）:

```markdown
---
time: 2026-09-27 08:55:58
title: 260927085557
attribute: group
---

# 260927085557

[DeepSeekへの従量課金よりもOpencode-goがいい](260927075132.md)
### Parent
### BackLink
```

- `h` / `Enter` は新ノートを**本文を空のまま**にし、`### Parent` にだけ
  「もと開いていたノート」を入れる（`s:simple_add_parent()`）。
- `p` は新ノートの本文に「もと開いていたノート」を**リンク 1 行**で置く
  （`s:simple_body_append_to_file()`）。グループ（`zk`）はリンクと `### Parent`
  が隣り合い、普通のノート（`zn`）は上下に空行 1 つずつ。
- `h` / `Enter` / `p` のどれを選んだかは「**今のノート側**に新ノートへのリンクを
  どこへ置くか」も決める。
- `zn` で `Enter` を選んだとき、リンクが `### Parent` の**上**（本文の最後）に
  くっつく場合は `s:ensure_blank_before_up()` で空行を入れる。

## タイトル・表示名

| キー | 動作 |
| --- | --- |
| `zt` | タイトル変更（空欄から開始） |
| `zT` | タイトル変更（現在タイトルを残して編集） |
| `zy` | **今開いているノート**の `title` の**よみ**を**空欄から**変更（`zt` と同じ流儀。Esc で中止）。対象ノートの `yomi:` に表示名が複数あるときは番号で表示名を選んでから編集 |
| `zY` | 同じ対象の**現在のよみ**（未登録なら pykakasi の推測）を残して編集（`zT` と同じ流儀）。全部消して `Enter` で削除。表示名の選択は `zy` と同じ |

変更すると、本文・Parent・BackLink のリンク表示名が追従（自動生成名のとき）。

## 移動・閲覧

| キー | 動作 |
| --- | --- |
| `<CR>` | カーソル下のリンクを開く |
| `<Tab>` / `<S-Tab>` | 次 / 前のリンクへ |
| `gs` | vault を**全文検索（タイトル優先）**。左はタイトル、右はヒット箇所をハイライト＋ヒット行へスクロール → `Enter` でそのノートのヒット行を開く |
| `<Space>` | 今のノートに表示中のリンクだけを fzf で一覧 → `Enter` で開く |
| `rg` | ripgrep で全文（行単位）検索（`:Rg`、fzf プレビュー付き） |
| `<BS>` | 履歴を戻る |
| `\h` | ハブ画面を開く（リンク一覧の**編集可能な Markdown**）。普通のリンクなので `1`〜`9`/`0` でそのまま移動できる |
| `\H` | 今のノートをハブにリンク 1 行として末尾へ追加 |
| `\1`〜`\9` | ハブ画面の N 番目のリンクへ直行 |
| `\0` | `\h` と同じ（ハブ画面を開く） |
| `\i` | `index.md` を開く（2打） |
| `\F` | 紙PKM Index（タイムスタンプ名）を作成/オープン。`Index_write` と `Folgezettel-Index` も作られる |
| `\f` | スキャン画像にフォルゲゼッテルIDを付けて vault 直下へ移動（番号付け GUI。`:SimpleScan`） |
| `\S`（ノーマル） | バッファ内の**リンクだけの行**を表示名のよみ順（五十音 → ローマ字は末尾）に安定ソート（主に `index.md`）。`:SortYomi` と同じ。`Index_write.md` ではキーワード行（`バナナ(ばなな): 1,2`）も並べる |
| `\S`（ビジュアル） | 選択した行のリンクだけの行を同じ規則でソート（リンクでない行は動かない） |
| `\S` の範囲 | 文章（リンクでない行）と、`### Parent` / `### Related` / `### BackLink` 以降のリンクは動かさない（グループに文章があってもそのまま） |
| `\I` | カーソル行（ビジュアルは選択範囲）の画像記法のサイズを変更（`SetImageSize`。旧 `\i`） |
| `\A` | ノートアプリ（Electron、無ければブラウザ）を開く |

- ハブは **Index（PKM ルート）ごと**に `~/.vim/simple_yurii_note/hubs/<hash>.md` に
  持つ（リンクを並べただけの Markdown。そのまま編集して保存すれば反映される）。
  旧 `hubs.json` は初回にこのファイルへ自動移行（json は残る）。
- `\S` / `:SortYomi` のよみは、リンク先ノートの front matter `yomi`（`zy` で登録）を
  優先し、未登録なら pykakasi が自動変換して**その場で `yomi:` に書き込む**
  （次回以降は辞書なしで同じ並び）。`zy` は手で正しいよみに直す/消すためのキー。
  pykakasi 未導入時は Unicode 順にフォールバック（`pip install --user pykakasi`）。
  詳細は `02-ノート形式.md` / `06-引き継ぎ.md`。

## 貼り付け（クリップボード）

| キー | 動作 |
| --- | --- |
| `\v` / `\V` | システムクリップボード（PCの直近のコピー / Vimでヤンクしたもの）を `p` / `P` の要領で貼る |
| `p` / `P` | Vim 標準（`"` レジスタ） |
| `gp` | 末尾改行を落として行下に追加 |
| `<C-v>` | システムクリップボードを貼る（挿入 / ノーマル / ビジュアル） |
| `<C-c>`（ビジュアル） | 選択をシステムクリップボードへコピー |
| `"+p` / `"+P` | Vim の `+` レジスタ経由（XWayland で古いことがあるので普段は使わない） |

- この Vim は `+` / `*` レジスタ（**XWayland 側**）を**使わない**（`set clipboard=`）。
  大きなヤンクを XWayland のクリップボードブリッジに通すと KWin / Klipper ごと
  固まることがあったため。読み書きは `wl-paste` / `wl-copy`（Wayland ネイティブ）で行う。
- Vim でヤンク（`yy` / `x` / `ciw` / `"+y` / `"*y`）した内容は `wl-copy` にも流れるので、
  `\v` でも PC 側のアプリでも貼れる。同期は非同期（Vim は待たない）。

## コマンド（主なもの）

| コマンド | 動作 |
| --- | --- |
| `:FSearch` | 全ノートを fzf で検索（`gs`） |
| `:LinkPick` | タイトル検索してリンク挿入（`\L`） |
| `:SimpleIndex` | `index.md` を開く |
| `:SimplePaperIndex` | 紙PKM Index（`paper_index: true` のタイムスタンプノート）を作成/オープン（`\F`） |
| `:SimpleScan` | スキャン画像の番号付け GUI を起動（`\f`。移動先は今開いているノートのフォルダ） |
| `:SortYomi` | バッファ内のリンク行を表示名のよみ順にソート（`\S` のノーマルと同じ。`Index_write.md` ではキーワード行も） |
| `:SimpleChooseIndex` / `:SimpleChooseIndexDir` | index ルート選択（別名 `:YuriiChooseIndex` 系） |
| `:SimpleGuide` | 操作ガイド `simple-yurii-note-guide.md` を作り直す（無ければ作る）。Index 作成時に Index と一緒に作り、Index 本文にリンクを 1 本置く（以後リンクを消しても復活しない）。起動時（VimEnter）は既存ガイドを最新テンプレートへ自動更新する |
| `:SimpleWeb` | ノートアプリ（Electron/ブラウザ）を開く（`\A`） |
| `:SimpleTable` | テーブル作成 |
| `:SimpleGallery` / `:SimpleGalleryFolder` | 画像ギャラリー |

- `:SimpleChooseIndex` は `input()` プロンプト。既定パスを**一気に消すには `<C-u>`**
  （カーソルは文末なので全部消える）。1単語ずつなら `<C-w>`、補完は `<Tab>`/`<C-d>`。

> 旧コマンド（`:UpdateMD` / `:UpdateAll` / `zt` の元名など）も一部残っている。
> 詳細は `plugin/simple_yurii_note/README.txt`。
