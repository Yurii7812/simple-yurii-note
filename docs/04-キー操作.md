# 04 キー操作（主なもの）

専用環境: `vim -u ~/.vimrc-simple-yurii-note`

## ノート作成

| キー | 動作 |
| --- | --- |
| `zn` | 子ノート作成（`h`=カーソル直下 / `Enter`・`p`=本文の最後 / `o`=孤立）。本文にリンクを1本、**新ノートの `### Parent` に元ノート**を書く |
| `zk` | グループノート作成（front matter に `attribute: group`）。位置キーは `zn` と同じ |

## リンク

| キー | 動作 |
| --- | --- |
| `\l`（ノーマル） | カーソル下のファイル名をリンク化 |
| `\l`（ビジュアル） | 選択範囲をリンクにして**新ノート作成**。「親に追加する？」を `y/n` で聞き、押したら新ノートを開く |
| `\p`（ノーマル） | クリップボードのリンクを挿入 |
| `\p`（ビジュアル） | クリップボードのファイル名を選択範囲のリンクに（ノートは開かない） |
| `za` | クリップボードのノートを**現ノートの `### Parent` の直前（本文末尾）**に追加する。`### BackLink` 側は触らない（sync が自動生成） |
| `\L` | カーソル下リンクの固定表示名トグル |
| `zp` | クリップボードの `.md` を**本文に追加**（＝今のノートが相手の親になる） |

## タイトル

| キー | 動作 |
| --- | --- |
| `zt` | タイトル変更（空欄から開始） |
| `zT` | タイトル変更（現在タイトルを残して編集） |

変更すると、本文・Parent・BackLink のリンク表示名が追従（自動生成名のとき）。

## 移動・閲覧

| キー | 動作 |
| --- | --- |
| `<CR>` | カーソル下のリンクを開く |
| `<Tab>` / `<S-Tab>` | 次 / 前のリンクへ |
| `<Space>` / `gs` | ノートナビゲータ（今のノートのリンク / 全ノート検索） |
| `<BS>` | 履歴を戻る |

## コマンド（主なもの）

| コマンド | 動作 |
| --- | --- |
| `:SimpleIndex` | `index.md` を開く |
| `:SimpleChooseIndex` / `:SimpleChooseIndexDir` | index ルート選択 |
| `:SimpleGuide` | 操作ガイドを作り直す |
| `:SimpleTable` | テーブル作成 |
| `:SimpleGallery` / `:SimpleGalleryFolder` | 画像ギャラリー |

> 旧コマンド（`:UpdateMD` / `:UpdateAll` / `zt` の元名など）も一部残っている。
> 詳細は `plugin/simple_yurii_note/README.txt`。
