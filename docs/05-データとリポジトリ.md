## 自動保存とバックアップ（2026-10-04〜）

自動保存は「書いた内容が消えないこと」、バックアップは「消した・壊した履歴を戻せること」を担う。

### 自動保存

- **アプリ**: 編集停止 約1.2秒で保存（従来どおり）。
- **Vim**: 最後の変更から **約5秒**（`g:simple_yurii_note_autosave_delay`）無操作で
  vault 配下の `.md` を `silent! update`。挿入・操作中は後回し。
  さらに **バッファ/ウィンドウを離れるとき・フォーカスを失ったときは即保存**
  （リンク間の移動は `:buffer` 等だと `'autowriteall'` が効かないため）。
  `g:simple_yurii_note_autosave = 0` で無効。保存後は BufWritePost autosync が走る。
- **Vim の永続 undo**: `vault/.undo/` に保存され、再起動後も `:earlier` / `:undolist` で戻せる。

### バックアップ（git）

- vault は git 管理（`~/files/yurii-note/.git`）。`.gitignore` は `*.swp` / `.undo/` /
  `_tmp/` / `.trash/` / `.pkm_*.json`。
- `~/.local/bin/yurii-note-backup`: 変更があり、かつ 60 秒以上アイドルなら
  `git add -A` → commit（「自動バックアップ 日時」）→ 全 remote へ push。
- `yurii-note-backup.timer`（systemd user・**2分ごと**・`Persistent=true`）が実行。
  手動実行は `systemctl --user start yurii-note-backup.service`。
- **保存先は2か所**:
  1. `~/files/yurii-note/.git`（index がある場所）
  2. `~/.vim-simple-yurii-note/yurii-note-backup.git`（ソフトウェア側の bare ミラー。
     vault から remote 名 `backup` で push）
  - 将来プライベート GitHub 等を足す場合は `git remote add <名前> <URL>` だけでよい
    （スクリプトが全 remote へ push する）。

### 復元

- アプリの削除は **ソフト削除**: `.trash/<日時>_<名前>` へ移動（一覧・sync には出ない）。
- `~/.local/bin/yurii-note-restore`: fzf で復元。
  - 引数なし … 消えた `.md` を選んで削除直前のコミットから戻す。
  - `<path>`  … そのファイルの過去版一覧から選んで上書き復元。
- 手動: `git log --oneline` / `git restore --source=<commit> -- <path>` / `git show <commit>:<path>`。
- `.trash` からの復元はファイルマネージャで戻す（`.trash` は vault 直下）。

## push ルール（厳守）

- プラグイン（`Yurii_PKM` / `simple-yurii-note`）に変更を加えたら、
  その作業の最後に **必ず** `git add -A` → `git commit`（日本語）→ `git push origin main`。
- push 後 `git status` がクリーンであることを確認する。
- ノート実体（`~/files/yurii-note`）は**バックアップ用のローカル git**として使う。
  GitHub 等への push はしない（`backup` ミラーのみ。外部へ出すなら明示的に追加する）。
