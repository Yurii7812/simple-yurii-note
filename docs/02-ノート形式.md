# 02 ノート形式

## 標準ノート

```markdown
---
time: 2026-09-27 03:35:06
title: ノート名
---

# ノート名

本文。ここにリンクを書く。書いたリンクが「子」になる。
[別ノート](260927033509.md) の話…

### Parent
[親ノート](index.md)
### BackLink
[このノートを参照しているノート](260927000000.md)
```

本文が**散文で終わっている**ときだけ、`### Parent` の直前に空行が 1 つ入る。
本文が**リンク行で終わっている**ときは（リンク群のあと）空行を挟まず `### Parent` が来る。
既に空行があれば重複しない（sync は本文の空行をそのまま通す）。

```markdown
# ノート名

本文だけ書いて終わるノート。

### Parent
[親ノート](index.md)
### BackLink
```

`za` / `zp` / `\p` / `zn`（`Enter`）がリンクを本文に置いたときは
**リンク行で終わる**ので `### Parent` は直前に続く（空行を挟まない）。
Enter で連続で 3 本置いても、**リンク同士の間には空行を入れない**
（1 つの連続ブロックとして扱う）。空行が累積しないこと。

```markdown
# ノート名

本文だけ書いて終わるノート。

### Parent
[親ノート](index.md)
### BackLink
```

### ルール

- **front matter**: `time`（作成時刻）, `title`（表示名）。グループは `attribute: group`。
  任意で `yomi`（表示名ごとのよみ。§よみ）を足せる。
- **本文（`# タイトル` の下）**: 自由。ここに置いた `[表示名](xxx.md)` が「子（outgoing）」。
- **`### Parent`**: 親へのリンク。**手書きで管理**する（書いたまま。同期は追加も削除もしない）。
  - 空行やメモ書きなど、リンク以外の行も保持される。
  - リンク行の**表示名だけ**は、相手のタイトル変更に追従して更新される。
- **`### BackLink`**: 本文でこのノートにリンクしている相手（incoming）から `Parent` にあるものを除いた一覧。自動生成。
- **`### Child` は存在しない**（廃止）。子は本文リンクで表す。
- 見出しは **`#` 3つ**（`### Parent` / `### BackLink`）。本文中の `##` 見出しと衝突しないため。

## グループ（index など）

`index.md`（グループ、`attribute: group`）は**セクションを持たない**。

```markdown
---
time: ...
title: Index
attribute: group
---

# Index
[日記](260909105059.md)
[ハーブ・薬草](260912101537.md)
```

- 本文の `.md` リンクが「子」になり、**リンク先の `### Parent` に Index が入る**。
- `### Parent` / `### BackLink` の見出しは置かない。

## よみ（yomi）

Index のリンクを**表示名のよみ順**に並べ替えるための、任意の front matter。
`zy` で登録する（表示名 1 つにつき 1 つのよみ）。

```yaml
---
time: ...
title: 筋トレ
yomi:
  "筋トレ": "きんとれ"
  "筋トレ日記": "きんとれにっき"
---
```

- キーはリンクの**表示名**、値はよみ（ひらがな / カタカナ / ローマ字）。
- 表示名がタイトルと同じなら `yomi` の同じキーを引く。表示名を変えたリンクは
  その表示名のキーを書く（1 ノートが複数の表示名を持てる）。
- 未登録の表示名は pykakasi が自動でよみに変換する（誤読もある。`筋トレ`→`すじとれ`）。
- どこからもリンクされなくなった表示名の `yomi` は、同期（`simple_sync`）時に
  自動で掃除される（ノート自身の `title` は残る）。
- 詳細は `04-キー操作.md`（`\S` / `zy`）と `06-引き継ぎ.md`。

## 命名・構造の慣習

- ファイル名はタイムスタンプ（`YYMMDDHHMMSS.md`）。タイトルは front matter の `title`。
- タイトルを変えてもファイル名は変えない（リンクはファイル名を指す）。
- 1ファイル=1ノート。アトミックにしすぎず、文章として書く。
